# 🛡️ Bug Bounty CLI Toolkit

This is a multi-language, terminal-friendly CLI tool for bug bounty reconnaissance and vulnerability hunting.

## 🚀 Branches

| Branch       | Purpose                           |
|--------------|------------------------------------|
| `main`       | Stable Bash CLI tool              |
| `bash-dev`   | Extended Bash script features     |
| `python-dev` | Python CLI with real-time APIs    |
| `c-dev`      | Low-latency binary (compiled CLI) |

## 📦 Setup

```bash
chmod +x bugbounty.sh
./bugbounty.sh -a
