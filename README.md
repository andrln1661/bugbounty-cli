# 🛡️ Bug Bounty CLI Toolkit (bash-dev)

This Bash-based command-line toolkit helps researchers, red teamers, and bug bounty hunters quickly reference, search, and manage tools by vulnerability types and use cases.

---

## 🚀 Features

- View a curated list of tools with:
  - 🔍 `-n` search by tool name
  - 🛡️ `-v` search by vulnerability
  - 📋 `-a` list all tools
- Clean terminal formatting
- Modular design with `tool_printer.sh` and `tool_filter.sh`
- Easy-to-edit external tool database (`tools.db`)
